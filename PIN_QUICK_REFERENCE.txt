## Pin Critical Notes

### ⚠️ CRITICAL: GPIO35 (GAS Sensor)
- **THIS PIN WAS MISSING** in the original code
- Dust sensor was incorrectly reading from GPIO34 (same as dust)
- **FIX APPLIED**: Now uses separate GPIO35 for gas sensor
- Verify your physical wiring connects gas sensor to GPIO35, NOT GPIO34

### GPIO34 vs GPIO35 (Both ADC1)
- GPIO34 (ADC1_CH6): Dust sensor - CORRECT ✓
- GPIO35 (ADC1_CH7): Gas sensor - CORRECT ✓
- **Do NOT use GPIO32, GPIO33** - they are ADC2 (WiFi conflicts)

### GPIO26-27 (Control outputs)
- GPIO26: Dust sensor LED timing control
- GPIO27: Buzzer alarm
- Both have strict timing requirements

## Power Connections

```
ESP32 3V3 ──┬──→ Dust Sensor VIN
            ├──→ Gas Sensor VIN
            ├──→ LEDs (via resistor)
            └──→ Buzzer (via transistor if needed)

ESP32 GND ──┬──→ Dust Sensor GND
            ├──→ Gas Sensor GND
            ├──→ LEDs
            └──→ Buzzer
```

## Getting Help

1. **Serial Output shows garbage?** → Check baud rate is 115200
2. **ADC stuck at 0 or 4095?** → Verify correct GPIO and 3.3V supply
3. **LED won't light?** → Check 330Ω resistor and polarity
4. **Buzzer silent?** → May need external transistor driver for 3.3V GPIO
5. **Gas sensor always 0%?** → Make sure it's connected to GPIO35 (not 34!)

## Verification Checklist

On startup, you should see in serial:
```
========================================
Air Detector - INITIALIZED
========================================
Dust Sensor   : GPIO34 (ADC1_CH6)
Dust LED      : GPIO26 (IR control)
Gas Sensor    : GPIO35 (ADC1_CH7)
Red LED       : GPIO14
Yellow LED    : GPIO13
Green LED     : GPIO12
Buzzer        : GPIO27
========================================
```

If any GPIO number is different, your wiring doesn't match the code.
